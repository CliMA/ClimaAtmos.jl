# Offline many-bin sea-salt column

The implicit solver's compile cost grows superlinearly with the number of prognostic
tracer names (field-matrix name inference), so a many-bin "truth" column cannot be run
inside the implicit state. Because the aerosols are passive, the truth run is instead
driven offline from the saved state of a cheap online run:

1. **Online run** (`online_2bin*.yml`): the column with 2 bins (submicron / supermicron,
   `ssa_2bin_1um.toml`) and optionally the `SSLTH` history tracers, with the full
   prognostic state written to HDF5 every step (`dt_save_state_to_disk` = `dt`).
   `reproducible_restart: true` makes the cache a pure function of the state (the
   cloud-fraction Picard iteration is otherwise seeded from the previous call);
   `hyperdiff: ~` because hyperdiffusion is a no-op in a column.
2. **Offline driver** (`offline_bins.jl`): builds an N-bin column with an explicit
   algorithm (no Jacobian is compiled), then for every pair of saved states linearly
   interpolates the non-aerosol fields into its own state, rebuilds the cache with
   `set_precomputed_quantities!`, evaluates `implicit_tendency!` +
   `remaining_tendency!`, and applies only the aerosol parts with Heun sub-steps
   (`dt` of the offline config = sub-step; every aerosol cap reads `p.dt`), followed
   by the model's own non-negativity clamp and updraft filter.
3. **Validation** (`offline_bins_validation.py`): offline 2-bin vs online 2-bin
   (burden error 0.1 % on Bomex), sub-bin sums vs the 2 bins, spectra, history tracers.

Bin overrides are generated by `bins_n.jl` (edges in µm → ClimaParams arrays whose
total emission equals the 5-bin default). `ssa_24bin.toml` / `ssa_50bin.toml` nest
exactly inside the 1 µm split. Measured on `clima` (Bomex, 1M, 6 h): explicit builds
2 bins 300 s, 24 bins 913 s, 50 bins 6421 s plus more than an hour compiling the first
tendency evaluation; integration 700 s (2 bins) and 2400 s (24 bins), 13140 s (50 bins, incl. the first-call compile).

Submit wrappers assume the `~/autodebug` probe layout (`probe_setup.sh <sha>`).
