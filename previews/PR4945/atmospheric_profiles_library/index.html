Atmospheric Profiles Library

ClimaAtmos.AtmosphericProfilesLibrary holds the published reference profiles that the single-column setups build on.

ClimaAtmos.AtmosphericProfilesLibrary — Module
AtmosphericProfilesLibrary

Published reference profiles for single-column and LES cases (BOMEX, DYCOMS, GABLS, Rico, TRMM-LBA, ...), in SI units.

Each profile is a function case_variable(::Type{FT}) that returns a type-stable callable wrapped in one of the AbstractProfile subtypes, which name its arguments:

  • ZProfile: prof(z)
  • TimeProfile: prof(t)
  • TimeZProfile: prof(t, z)
  • ΠZProfile: prof(Π, z), where Π is the Exner function
  • ΠTimeZProfile: prof(Π, t, z)

A few functions such as TRMM_LBA_z return the raw data grid instead, and Larcform1_constants returns the Larcform1 case constants.

The module depends only on interpolation packages, not on the rest of ClimaAtmos.

Examples

import ClimaAtmos.AtmosphericProfilesLibrary as APL
θ = APL.Bomex_θ_liq_ice(Float64)
θ(500.0)
